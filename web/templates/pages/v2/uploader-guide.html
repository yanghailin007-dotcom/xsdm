📖 大文娱小说发布助手 - 完整使用指南

从下载工具到成功发布，一步一步教你完成全自动发布

1
下载上传工具

首先，你需要下载桌面端上传工具 NovelPublisher.exe

下载方式：
  1. 返回上传页面
  2. 点击「立即下载上传工具」按钮
  3. 保存 NovelPublisher.exe 到你的电脑
注意事项：
  • 第一次运行可能会被 Windows 防火墙拦截，请选择「仍要运行」
  • 如果缺少 Chrome 浏览器，工具会自动提示下载（约150MB）
2
准备项目数据

在使用上传工具之前，你需要从网页下载项目数据：

  1. 进入番茄上传页面
  2. 选择你要发布的小说项目
  3. 编辑书籍信息（书名、分类、简介等）
  4. 点击「下载配置」和「下载数据」按钮
下载的文件说明：
  • 配置文件（JSON）：包含书名、简介、发布设置等
  • 项目数据（ZIP）：包含所有章节内容
3
解压项目数据

将下载的 ZIP 文件解压到你的电脑：

  1. 找到下载的 ZIP 文件（如 project_data_项目名.zip）
  2. 右键 ZIP 文件 → 选择「解压到当前文件夹」或「解压到 xxx」
  3. 解压后会得到一个项目文件夹
解压后的目录结构应该是： 
项目文件夹/
├── chapters/          # 章节目录
│   ├── chapter_001.json
│   ├── chapter_002.json
│   └── ...
├── project_config.json  # 配置文件
└── cover.jpg           # 封面图片（如果有）
4
使用上传工具

现在可以打开上传工具开始发布了：

  1. 运行工具：双击 NovelPublisher.exe
  2. 选择项目：点击「选择目录」按钮，选择刚才解压的项目文件夹
  3. 等待加载：工具会自动读取配置并加载章节列表
选择章节：
  • 在章节列表中勾选要上传的章节（默认全选）
  • 可以使用「全选」或「取消全选」快速选择
  • 第一次发布建议先上传 3-5 章测试
5
配置发布参数

根据需要调整上传参数：

  • 最小/最大延迟：建议保持 3-8 秒，模拟人工操作避免风控
  • 出错停止：如果某章上传失败是否自动停止
  • 窗口置顶：上传时是否最小化到系统托盘
风控建议：
  • 首次使用建议先上传少量章节测试（如 3-5 章）
  • 确认正常后再批量上传
  • 不要频繁操作，避免触发平台安全机制
6
开始上传

一切准备就绪，开始上传：

  1. 点击「开始上传」按钮
  2. 工具会自动打开 Chrome 浏览器
  3. 在浏览器中登录你的番茄作者账号（首次需要）
  4. 工具会自动完成以下操作：
    • 创建新书（如果不存在）
    • 填写书籍信息
    • 上传封面
    • 逐章上传内容
上传过程中：
  • 请不要关闭 Chrome 浏览器
  • 不要操作鼠标和键盘
  • 可以最小化窗口后台运行
✓
完成发布

🎉 恭喜！你已成功完成小说发布！

上传完成后，你可以：

  • 在番茄作者后台查看已发布的章节
  • 继续使用工具发布更多章节
  • 编辑或修改已发布的内容
🚀 立即开始发布

❌ 常见问题

上传失败怎么办？ +

1. 检查网络连接是否正常

2. 确认番茄作者账号已正确登录

3. 检查项目配置是否完整

4. 尝试增加延迟时间，避免操作过快

可以修改已发布的章节吗？ +

可以。工具会自动跳过已发布的章节，你也可以手动在番茄作者后台修改。

支持哪些平台？ +

当前主要支持番茄小说。起点中文网、纵横中文网等其他平台正在开发中。
