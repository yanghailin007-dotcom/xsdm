## 6. 使用说明

### 6.1 访问导出页面

用户点击"导出"按钮后，将跳转到:
```
/export-page/<小说标题>
```

### 6.2 导出配置选项

在导出页面，用户可以配置:
1. 导出模式(正文/项目)
2. 文件格式(TXT/MD)
3. 内容选项(标题/简介/分隔线)
4. 导出范围(全部/指定)

### 6.3 下载文件

点击"开始导出"后，浏览器将直接下载文件:
- 正文导出: `<小说名>_正文.txt` 或 `.md`
- 项目导出: `<小说名>_小说项目导出.zip`
