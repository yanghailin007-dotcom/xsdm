大文娱小说发布助手
===================

📦 文件说明
-----------
NovelPublisher.exe      - 小说自动发布助手主程序（双击运行）
chrome_manager.py       - Chrome 浏览器管理模块
fanqie_uploader_impl.py - 番茄小说上传实现
启动.bat                - 快速启动脚本

⚠️  重要提示：首次使用需要下载 Chrome（约 150MB）
==================================================
本工具需要 Chrome 浏览器才能自动操控网页上传。

首次使用时：
1. 双击运行 NovelPublisher.exe
2. 如果检测到未安装 Chrome，会弹出提示
3. 点击"是"自动下载 Chrome（约 150MB，耗时 1-3 分钟）
4. 下载完成后即可正常使用，下次无需重复下载

如果您已安装 Chrome，工具会自动检测并使用。

🚀 核心功能
-----------
✅ 支持多平台：番茄小说、起点、纵横等（配置选择）
✅ 自动下载/检测 Chrome 浏览器
✅ 可视化项目选择
✅ 章节批量自动上传
✅ 实时进度显示
✅ 智能风控延迟设置
✅ 登录状态自动保持

💻 系统要求
-----------
- Windows 10/11 64位
- 网络连接（首次需要下载 Chrome）
- 磁盘空间：至少 200MB 可用空间

📖 使用方法
-----------

第1步：启动工具
  双击运行 NovelPublisher.exe

第2步：下载 Chrome（仅首次）
  如果弹出下载提示，点击"是"下载 Chrome
  下载进度会显示在日志区域

第3步：选择平台配置
  1. 在配置界面选择目标平台（如：番茄小说）
  2. 工具会自动生成对应平台的上传配置

第4步：选择项目
  1. 在"项目"下拉框中选择要上传的小说
  2. 点击"刷新"可重新扫描项目列表

第5步：选择章节
  1. 勾选要上传的章节（可多选）
  2. 使用"全选"/"全不选"按钮快速选择

第6步：配置上传选项
  - 最小/最大延迟：建议 3-8 秒，用于规避风控
  - 出错停止：上传失败时是否停止

第7步：开始上传
  1. 点击"开始上传"按钮
  2. 工具会自动启动 Chrome
  3. 在 Chrome 中登录对应平台的作者账号（首次需要）
  4. 工具会自动完成上传并显示进度

第8步：查看结果
  - 上传成功的章节显示绿色
  - 上传失败的章节显示红色
  - 日志区域显示详细进度

⚙️ 工作原理
-----------
本工具采用**统一核心 + 平台适配**架构：

1. 核心引擎（chrome_manager.py）
   - 统一的 Chrome 浏览器控制
   - 自动检测/下载 Chrome
   - 调试端口 9988 连接

2. 平台适配层（*_uploader_impl.py）
   - 番茄小说：fanqie_uploader_impl.py
   - 起点中文网：qidian_uploader_impl.py（开发中）
   - 其他平台：陆续接入

3. 配置生成器
   - 根据选择的目标平台
   - 自动生成对应的上传脚本包
   - 包含平台特定的选择器和逻辑

📋 注意事项
-----------
1. Chrome 下载：
   - 首次运行如未安装 Chrome，工具会自动下载（约 150MB）
   - 下载可能需要 1-3 分钟，取决于网络速度
   - 请保持网络连接稳定

2. Chrome 使用：
   - 下载完成后，请保持 Chrome 窗口打开
   - 不要在关闭 Chrome 的情况下进行上传

3. 登录状态：
   - 每个平台首次需要手动登录
   - 登录状态会按平台分别保存
   - 下次发布到同一平台无需重复登录

4. 风控策略：
   - 建议使用 3-8 秒的随机延迟
   - 每次不要上传过多章节（建议不超过 50 章）
   - 避免在高峰期大批量上传

5. 书籍要求：
   - 请先在对应平台的作者中心创建书籍
   - 工具会自动查找匹配的书籍
   - 如未找到书籍会提示手动创建

❓ 故障排查
-----------
Q: 提示需要下载 Chrome？
A: 首次使用需要下载 Chrome（约 150MB），点击"是"即可自动下载。
   如下载失败，可访问 https://novel-ai.online/ 获取帮助。

Q: Chrome 下载失败？
A: 1. 检查网络连接是否正常
   2. 检查磁盘空间是否充足（至少 200MB）
   3. 尝试重新启动工具
   4. 或自行安装 Chrome 浏览器后再使用

Q: 提示 "Chrome 启动失败"？
A: 1. 检查是否已安装 Chrome 浏览器
   2. 检查 9988 端口是否被占用
   3. 尝试重新启动工具

Q: 提示 "未登录"？
A: 在打开的 Chrome 窗口中访问对应平台网站并登录作者账号

Q: 提示 "未找到书籍"？
A: 请先在对应平台的作者中心创建书籍，确保书名与工具中显示的一致

Q: 上传失败？
A: 1. 检查网络连接
   2. 查看日志详情
   3. 确认平台网站可正常访问
   4. 可能是平台页面结构变化，等待工具更新适配
   5. 访问官网 https://novel-ai.online/ 获取技术支持
