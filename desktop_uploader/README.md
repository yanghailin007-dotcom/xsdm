# 小说自动上传工具 - 桌面版

基于现有上传脚本封装的GUI桌面应用，完全复用核心上传逻辑。

## 功能特点

- ✅ **可视化界面** - 图形化操作，无需命令行
- ✅ **章节管理** - 勾选上传，支持批量选择
- ✅ **进度显示** - 实时进度条和日志
- ✅ **智能风控** - 可配置延迟策略
- ✅ **系统托盘** - 后台运行，不打扰工作
- ✅ **完全复用** - 零改动现有上传逻辑

## 快速开始

### 方式1：直接运行源码（开发）

```bash
# 1. 进入目录
cd desktop_uploader

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python main.py
```

### 方式2：打包成EXE（分发）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行打包脚本
python build.py

# 3. 输出文件在 dist/小说自动上传工具.exe
```

## 与纯脚本的区别

| 功能 | 纯脚本 | 桌面应用 |
|------|--------|----------|
| 界面 | 命令行黑窗 | 图形界面 |
| 操作 | 编辑配置文件 | 点击按钮 |
| 进度 | 文字输出 | 进度条+日志框 |
| 后台 | 占用命令行 | 托盘后台运行 |
| 代码量 | 现有脚本 | +300行GUI |

## 配置说明

### 默认配置 (config.json)

```json
{
  "delay_min": 3,        // 最小延迟(秒)
  "delay_max": 8,        // 最大延迟(秒)
  "stop_on_error": false // 出错时是否停止
}
```

### 界面设置

- **延迟范围**：上传章节间的随机等待时间（风控）
- **出错停止**：遇到上传失败时是否中断
- **最小化到托盘**：上传时自动隐藏窗口

## 🔐 安全加密

### 多层保护机制

1. **代码混淆** (`obfuscator.py`)
   - 变量名随机化 (12-24位随机字符)
   - 移除注释和文档字符串
   - 添加反调试代码
   
2. **配置加密**
   - XOR + Base64 加密敏感配置
   - 随机密钥 (32位)

3. **EXE打包保护**
   - PyInstaller单文件打包
   - UPX压缩（可选）
   - 隐藏源代码

### 打包命令

```bash
# 普通打包（无加密）
python build.py

# 安全打包（加密混淆）⭐推荐
python build_secure.py

# 验证文件完整性
python verify.py --file "dist/小说自动上传工具.exe" --save
```

### 反编译难度

| 保护级别 | 代码可读性 | 逆向难度 | 适用场景 |
|---------|-----------|---------|---------|
| 无保护源码 | 完全可读 | ⭐ 极易 | 内部使用 |
| 普通EXE | 可反编译 | ⭐⭐ 容易 | 测试分发 |
| 加密EXE | 混淆代码 | ⭐⭐⭐⭐ 困难 | ⭐ 正式发布 |
| 加密+校验 | 混淆+验证 | ⭐⭐⭐⭐⭐ 极难 | 高安全需求 |
