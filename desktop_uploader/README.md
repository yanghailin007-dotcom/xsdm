# 大文娱小说发布助手 v1.2

## 简介

**大文娱小说发布助手**是一个统一的桌面端自动发布工具，支持多平台小说上传。通过配置选择目标平台，自动生成对应的上传脚本，实现一键批量发布。

## 核心特性

- 🚀 **多平台支持**：番茄小说、起点、纵横等（陆续接入）
- 🎯 **配置化发布**：选择平台 → 生成配置 → 自动上传
- 🖥️ **可视化界面**：PyQt5 GUI，项目选择、章节管理、进度显示
- 🔧 **智能适配**：自动下载 Chrome，平台特定逻辑适配
- 📊 **实时反馈**：上传进度、成功/失败状态实时显示

### 模块说明

| 模块 | 文件 | 说明 |
|-----|------|------|
| GUI 主程序 | `main.py` | PyQt5 界面，项目/章节管理 |

## 快速开始

### 方式一：运行 EXE（推荐）

```bash
cd desktop_uploader/release
双击 NovelPublisher.exe
```

### 方式二：运行源码

```bash
cd desktop_uploader
pip install PyQt5 playwright
playwright install chromium
python main.py
```

## 使用流程

```
1. 启动工具 → 检测/下载 Chrome（首次）
        ↓
2. 选择平台 → 番茄/起点/纵横
        ↓
3. 生成配置 → 自动加载平台适配逻辑
        ↓
4. 选择项目 → 本地小说项目
        ↓
5. 选择章节 → 勾选要上传的章节
        ↓
6. 开始上传 → 自动打开 Chrome → 登录 → 上传
        ↓
7. 查看结果 → 成功/失败状态显示
```

## 构建方法

```bash
cd desktop_uploader
python -m PyInstaller \
    --name NovelPublisher \
    --onefile --windowed \
    --add-data "libs;libs" \
    main.py
```

## 添加新平台适配

1. 创建平台上传实现：`{platform}_uploader_impl.py`
2. 实现 `upload_chapter()` 方法
3. 在配置中添加平台选项
4. 更新平台适配映射表

## 注意事项

1. **需要 Chrome 浏览器**：如未安装，工具会自动下载 Chrome for Testing（约 150MB）
2. **首次登录**：每个平台首次使用需要手动登录
3. **风控策略**：建议设置 3-8 秒随机延迟，避免频繁操作
4. **书籍准备**：请先在对应平台作者中心创建书籍
