# 大文娱小说发布助手 - 快速开始

## 工具定位

**大文娱小说发布助手**是一个统一的自动发布工具，支持多平台配置。

不是"某某平台专用工具"，而是**一个工具 + 多平台配置**。

---

## 需要下载 Chrome 吗？

**已安装 Chrome**：工具会自动检测并使用  
**未安装 Chrome**：首次使用会提示下载（约 150MB）

---

## 运行方式

### 方式一：直接运行 EXE（推荐）

```
desktop_uploader/release/
├── NovelPublisher.exe    <- 双击运行（统一的发布助手）
├── 使用说明.txt
└── 启动.bat
```

### 方式二：运行 Python 源码

```bash
cd desktop_uploader
pip install PyQt5 playwright
playwright install chromium
python main.py
```

## 使用步骤

### 第 1 步：启动工具
双击运行 `NovelPublisher.exe`

### 第 2 步：下载 Chrome（仅首次）
- 如弹出下载提示，点击"是"下载 Chrome
- 下载进度会显示在日志区域
- 耗时约 1-3 分钟

### 第 3 步：选择发布平台
在配置界面选择目标平台：
- 🍅 番茄小说（已支持）
- 📚 起点中文网（开发中）
- 📝 纵横中文网（计划中）

工具会自动加载对应平台的上传逻辑。

### 第 4 步：选择项目
- 在"项目"下拉框中选择要上传的小说
- 点击"刷新"可重新扫描项目列表

### 第 5 步：选择章节
- 勾选要上传的章节（可多选）
- 使用"全选"按钮快速选择所有章节

### 第 6 步：配置上传选项
- **最小/最大延迟**：建议保持 3-8 秒，用于规避风控
- **出错停止**：勾选后如果某章上传失败会停止

### 第 7 步：开始上传
1. 点击"开始上传"按钮
2. 工具会自动打开 Chrome
3. 在 Chrome 中登录对应平台的作者账号（首次需要）
4. 工具会自动完成上传并显示进度

### 第 8 步：查看结果
- 上传成功的章节显示绿色
- 上传失败的章节显示红色
- 日志区域显示详细进度

## 平台切换说明

本工具是**统一的发布助手**，不是多个独立工具。

切换平台只需在配置界面重新选择：
1. 工具会自动加载对应平台的适配逻辑
2. 生成平台特定的上传配置
3. 调整元素定位和操作流程

各平台的登录状态分别保存，互不影响。

## 首次使用注意事项

1. **Chrome 下载**：首次运行如未安装 Chrome，工具会自动下载（约 150MB），请耐心等待
2. **平台登录**：每个平台首次需要手动登录，之后会自动保持登录状态
3. **风控**：建议首批上传少量章节测试（5-10 章），确认正常后再批量上传

## 故障排查

| 问题 | 解决方案 |
|-----|---------|
| 提示需要下载 Chrome | 点击"是"下载，或自行安装 Chrome 后重启工具 |
| Chrome 下载失败 | 检查网络和磁盘空间，或访问官网获取帮助 |
| 提示 "未登录" | 在 Chrome 中登录对应平台的作者账号 |
| 提示 "未找到书籍" | 请先在平台作者中心创建书籍 |
| 上传失败 | 检查网络、查看日志、确认网站可访问 |
