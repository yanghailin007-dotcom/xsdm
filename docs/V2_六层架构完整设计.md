## 设计原则

### 1. 单一职责原则
- 每层只负责一个维度的约束
- 层与层之间低耦合
- 每层可独立更新和版本控制

### 2. 动态组装原则
- 所有提示词运行时动态组装
- 无静态硬编码内容
- 支持参数化配置

### 3. 题材隔离原则
- Layer 3 题材技法完全隔离
- 不同题材互不干扰
- 新增题材只需添加YAML文件

### 4. 可验证原则
- 每层输出可独立验证
- Layer 6 自检清单强制执行
- 质量不达标自动重写

## Layer 4: 文风技法 (WritingStyle)

### 作用
所有题材通用的写作技巧，提升阅读体验。

### 数据结构

```yaml
# writing_style.yaml
version: "1.0"

# 1. 段落规范
paragraph:
  max_lines: 3
  avg_length: "30-50字"
  mobile_first: true
  
  examples:
    good: |
      "就这？"
      
      陈默嘴角微微上扬。
      
      "你确定？"
    
    bad: |
      陈默看着张昊，心里想着这个人真是太嚣张了，
      他决定要给这个人一点教训看看，
      于是他开口说道："你确定要惹我？"（叙述过多）

# 2. 句子规范
sentence:
  short_ratio: 0.6
  max_length: 15
  colloquial: true
  
  short_sentence_examples:
    - "就这？"
    - "你确定？"
    - "蝼蚁。"
    - "记账了。"

# 3. 对话规范
dialogue:
  ratio: 0.5
  format: "引号\"\""
  one_per_paragraph: true
  tags: ["他说", "笑道", "冷声道", "怒吼", "喃喃"]
  
  techniques:
    - name: "短对话推动"
      description: "一句一段，快速推进"
      example: |
        "交出宝物。"
        
        "凭什么？"
        
        "凭这个。"
        
        陈默亮出了令牌。
    
    - name: "对话+动作"
      description: "对话中穿插动作，增加画面感"
      example: |
        "你确定？"陈默缓缓抬起头。
        
        张昊一愣："什么？"
        
        "我说——"陈默眼神如刀，"你确定要惹我？"

# 4. 节奏控制
pacing:
  conflict_first_300: true
  mini_burst_every_1000: true
  hook_last_50: true
  no_dialogue_limit: 200
  
  chapter_rhythm:
    - position: "0-300字"
      must_have: "冲突/悬念/钩子"
      forbidden: ["环境描写", "背景介绍"]
    
    - position: "300-1500字"
      must_have: "情绪递进"
      recommended: ["小反转", "小爽点"]
    
    - position: "1500-2000字"
      must_have: "核心爽点"
      requirement: "强度≥8"
    
    - position: "2000-2200字"
      must_have: "章尾钩子"
      forbidden: ["完美收尾", "皆大欢喜"]

# 5. 震惊流技法
shock_flow:
  principles:
    - name: "先反应后原因"
      description: "先写众人反应，再揭示原因，制造悬念"
      example: |
        全场死寂。
        
        所有人瞪大了眼睛，张大了嘴巴。
        
        发生了什么？
        
        原来就在刚才...
    
    - name: "层层递进"
      description: "按空间/地位顺序递进，禁止跳级"
      correct_order: ["现场→围观→权威→全网"]
      forbidden: ["跳过层级", "同时震惊所有人"]
    
    - name: "数字量化"
      description: "用具体数字替代模糊描述"
      examples:
        - before: "实力提升很多"
          after: "战力从1000提升到9876"
        - before: "速度很快"
          after: "3秒内完成"

# 6. 情绪控制
emotion_control:
  transitions_per_chapter: 3
  climax_intensity: 8
  no_regression: true
  
  emotion_arcs:
    - name: "打脸弧"
      curve: "憋屈→紧张→反转→爽"
    - name: "收获弧"
      curve: "期待→惊险→成功→爽"
    - name: "危机弧"
      curve: "平静→危机→绝望→逆转→爽"

# 7. 微创新原则
micro_innovation:
  principles:
    - name: "结构对标，内容创新"
      description: "遵循成功模式，但创造新情节"
      example: "同样是打怪升级，但怪物特性、战斗方式要新颖"
    
    - name: "反套路"
      description: "在读者预期处反转让步"
      example: "反派求饶时，主角说'晚了'，干脆利落"
    
    - name: "细节差异化"
      description: "在细节上创造记忆点"
      example: "主角标志性动作：嘴角微扬、负手而立"

# 8. 禁止事项
forbidden:
  content:
    - item: "爽点回退"
      description: "爽后突然压抑（番茄大忌）"
      example: "刚打脸成功，突然被告知有更大危机"
    
    - item: "预告欺诈"
      description: "章尾预告不兑现"
      example: "预告'下一章必死'，结果没事"
    
    - item: "人设崩塌"
```
