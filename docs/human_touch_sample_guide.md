# 头部作品样本收集指南

## 一、为什么需要样本？

要让AI写出"有人味"的文章，首先需要知道"人味"长什么样。通过分析番茄头部作品，我们可以：

1. **量化"人味"特征** - 用数据定义什么是好的写作
2. **提取风格DNA** - 学习头部作品的写作模式
3. **建立对比基准** - 评估AI生成文本的差距

## 二、收集什么作品？

### 2.1 选择标准

**必须是**
- 番茄小说头部作品（阅读量100万+）
- 你认为"写得很好、读起来顺畅"的作品
- 不同题材都要有样本

**优先选择**
- 近期爆款（反映当前平台偏好）
- 完结作品（质量稳定）
- 评分9.0+的作品

### 2.2 题材覆盖

| 题材类型 | 代表作品 | 特征 |
|---------|---------|------|
| 赘婿/战神 | 《上门龙婿》《绝世强龙》 | 快节奏、强冲突、口语化 |
| 玄幻修仙 | 《道诡异仙》《斩神》 | 世界观宏大、描写细腻 |
| 都市脑洞 | 《开局地摊卖大力》 | 轻松幽默、反套路 |
| 年代/种田 | 《重生八零》《农家小福女》 | 生活气息、细节丰富 |
| 悬疑灵异 | 《我有一座冒险屋》 | 氛围营造、节奏控制 |

建议：每个题材至少收集2-3本，每本3-5个章节样本

## 三、如何收集？

### 3.1 使用收集工具

```bash
cd C:\work\xsdm
python tools/sample_collector.py
```

### 3.2 交互式录入步骤

**Step 1: 添加小说信息**
```
书名: 上门龙婿
作者: 公子墨
题材类型: 赘婿
总章节数: 2356
评分: 9.2
为什么选择这本: 节奏快，对话自然，打脸爽点密集
风格标签: 热血,快节奏,强冲突
```

**Step 2: 添加章节样本**

建议选取：
- **开头**（第1-3章）- 学习如何抓人眼球
- **转折**（约30%处）- 学习情节推进
- **高潮**（约70%处）- 学习爽点营造
- **结尾**（最后几章）- 学习收尾技巧

**录入内容格式：**
```
章节号: 1
章节标题: 废物女婿

章节内容(输入END结束):
叶辰站在别墅门口，深吸了一口气。
这是他结婚三年来，第一次踏进萧家的大门。
"哟，这不是我们萧家的废物女婿吗？"
一道尖酸刻薄的声音传来...
END
```

### 3.3 批量导入（适合大量样本）

创建JSON文件（`samples.json`）：
```json
[
  {
    "title": "上门龙婿",
    "author": "公子墨",
    "genre": "赘婿",
    "rating": 9.2,
    "sample_reason": "节奏快，对话自然",
    "style_tags": ["热血", "快节奏"],
    "chapters": [
      {
        "chapter_number": 1,
        "title": "废物女婿",
        "content": "叶辰站在别墅门口..."
      }
    ]
  }
]
```

导入命令：
```bash
python tools/sample_collector.py --import samples.json
```

## 四、样本质量检查

录入后系统会自动分析每章的"人味指标"：

### 4.1 关键指标解释

| 指标 | 健康范围 | 说明 |
|-----|---------|------|
| **人味分数** | 60-90 | 整体评分，越高越像真人写作 |
| **句长方差** | 15-40 | 句式变化程度，AI通常<10 |
| **感官密度** | 0.03-0.06 | 五感描写丰富度 |
| **破碎句比例** | 0.1-0.2 | 短句/破碎句占比 |

### 4.2 异常检查

如果某章指标异常，可能是：
- **句长方差<5** - 太像AI，句式太整齐
- **人味分数<40** - 可能是平台简介或非正文内容
- **感官密度<0.01** - 描写太抽象，缺少细节

## 六、快速开始

### 最小可行收集（30分钟）

1. **选3本书** - 你最喜欢的番茄头部作品
2. **每本选3章** - 开头、中间、结尾各1章
3. **使用工具录入** - 运行 `python tools/sample_collector.py`
4. **验证指标** - 确保人味分数在合理范围

完成！现在系统可以基于这些样本分析AI生成文本的差距。

## 八、常见问题

**Q: 可以直接复制粘贴网页内容吗？**
A: 可以，但建议清理掉"上一章"/"下一章"等非正文内容。

**Q: 样本需要多少字？**
A: 每章至少1000字，建议完整章节（2000-3000字）。

**Q: 已经录入的样本可以修改吗？**
A: 目前需要直接操作数据库，后续会增加编辑功能。

**Q: 为什么要人工录入，不能爬虫吗？**
A: 爬虫有法律风险，且人工选择能保证样本质量。
