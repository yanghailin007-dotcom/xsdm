## 四、逐章细纲（第1-10章）

### 第1章 《被裁员的那天，我银行卡只剩300块》

- **场景设定**：互联网公司楼下，傍晚6点，阴天。江辰抱着纸箱走出大楼，手机显示银行余额：300.50元
- **涉及角色**：江辰、HR（反派铺垫）、初恋林晓晓（电话出场）
- **核心爽点**：极端低谷铺垫，强烈代入感
- **具体情节**：
  1. 开场：江辰被裁员，HR假惺惺"公司优化"
  2. 发展：接到老妈电话，催婚+"村东头壮硕丫头"
  3. 碰撞：初恋林晓晓发来分手消息"你养不起我"，配图是和富二代男友
  4. 结尾：江辰坐在路边摊，咬着烤肠，内心OS："这个年，怎么过？"
- **关键对话**：
  - 老妈："辰辰啊，过年带女朋友回来不？"
  - 江辰："妈，我...工作忙..."
  - 老妈："忙忙忙！村东头翠花还等着呢！"
  - 江辰（内心）：翠花？那个200斤的壮硕丫头？
- **角色细节**：江辰推眼镜时手在抖，烤肠掉地上了，犹豫了三秒还是捡起来吃了（穷习惯）
- **状态更新**：主角财富300元，位置公司楼下，心情崩溃

### 第2章 《网吧里，我绑定了三个精神小妹》

- **场景设定**：城中村网吧，凌晨1点，烟雾缭绕，键盘声此起彼伏
- **涉及角色**：江辰、红毛（关珊珊）、蓝毛（麦麦）、金毛（瑶瑶）、网吧老板

  2. 发展：网吧老板欺负红毛拖欠网费，江辰下意识替红毛说话
  3. 碰撞：系统激活！眼前出现面板：【检测到潜在绑定对象×3，是否绑定？】
