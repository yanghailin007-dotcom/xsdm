# 分卷细纲生成页面设计方案

## 背景

当前正文生成页面中的"📋 生成本卷细纲"按钮是直接调用 API 输出，用户无法干预生成过程。实际创作中，每一卷的细纲需要根据：
- 核心设定（防漂移）
- 全书大纲（防偏离主线）
- 上一卷细纲（保持情绪连贯、伏笔回收）
- **作者的主观意图**（本卷重点、想调整的剧情、特殊要求）

因此需要一个**独立的分卷细纲生成页面**，支持用户查看上下文 + 输入补充要求 + 流式生成 + 编辑保存。

---

## 页面设计

### 页面信息
- **路由**：`/volume-outline-generation`
- **模板**：`web/templates/pages/v2/volume-outline-generation.html`
- **风格**：V2 暗黑主题，与正文生成页统一

### 布局（左侧面板 + 右侧输出）

```
┌─────────────────┬────────────────────────────────────────┐
│  📚 项目：xxx    │  📝 生成本卷细纲                        │
│  📖 卷号：第2卷  │                                        │
│                 │  （流式输出区 / 编辑区）                  │
│ ─────────────── │                                        │
│ 📖 核心设定      │                                        │
│ （只读，折叠）   │                                        │
│ ─────────────── │                                        │
│ 📄 全书大纲      │                                        │
│ （只读，折叠）   │                                        │
│ ─────────────── │                                        │
│ 📋 上一卷细纲    │                                        │
│ （只读，折叠）   │                                        │
│ ─────────────── │                                        │
│ ✏️ 补充要求      │                                        │
│ （用户编辑区）   │                                        │
│                 │                                        │
│ [✨ 开始生成]    │                                        │
│                 │                                        │
└─────────────────┴────────────────────────────────────────┘
```

### 左侧面板详细

| 区块 | 内容 | 交互 |
|------|------|------|
| 项目信息 | 项目名、卷号、模型选择 | 只读 |
| 📖 核心设定 | 自动加载 `settings.md` | 可折叠，默认折叠 |
| 📄 全书大纲 | 自动加载 `outline.md` | 可折叠，默认折叠 |
| 📋 上一卷细纲 | 自动加载 `detailed_outline_vol{N-1}.md` | 可折叠，默认折叠（第1卷无此区块） |
| ✏️ 补充要求 | textarea，用户自由输入 |  placeholder："本卷重点想写... / 想调整的剧情... / 特殊要求..." |
| 操作按钮 | ✨ 开始生成 | 点击后 SSE 流式输出 |

### 右侧面板详细

| 状态 | 显示内容 |
|------|----------|
| 未生成 | 提示文字："左侧确认上下文后点击开始生成" |
| 生成中 | SSE 流式输出，实时展示 AI 写作过程 |
| 生成完成 | Markdown 渲染的细纲 + [✏️ 编辑] [💾 保存] 按钮 |
| 编辑模式 | textarea 全屏编辑 |

## 后端 API 设计

### 1. 获取上下文
```
GET /api/conversation/volume-outline-context?project_id=xxx&volume=2
```

返回：
```json
{
  "success": true,
  "settings": "核心设定文本...",
  "outline": "全书大纲文本...",
  "prev_volume_outline": "上一卷细纲文本...",
  "has_prev": true
}
```

### 2. 流式生成分卷细纲
```
POST /api/conversation/generate-volume-outline-v2
```

请求体：
```json
{
  "project_id": "xxx",
  "volume_number": 2,
  "model": "deepseek-v4-pro",
  "user_notes": "本卷重点写林远和省里领导的博弈...",
  "messages": []
}
```

返回：SSE 流（与 `generate-batch` 相同格式）

### 3. 保存细纲
复用现有 `POST /api/conversation/save-project-files`

## Prompt 设计

```
你是番茄小说签约级别的专业网文策划。请根据以下信息生成本卷细纲。

【核心设定】
{settings}

【全书大纲】
{outline}

【上一卷细纲】
{prev_volume_outline}

【作者补充要求】
{user_notes}

---

## 输出要求

1. 本卷细纲必须严格围绕大纲中该卷的内容展开
2. 每章包含：
   - 场景设定（时间、地点、氛围）
   - 涉及角色
   - 核心爽点/猎奇点
   - 具体情节步骤（1.2.3.）
   - 关键对话示例（1-2句）
   - 爽点设计说明
3. 每章细纲 200-400 字
4. 章节之间情绪曲线连贯，每章结尾留钩子
5. 用 Markdown 格式：每章 "## 第X章 【抓眼球标题】"
6. 不要输出任何说明文字、总结、分析
```

---

## 数据流

```
1. 用户从正文生成页点击"📋 生成本卷细纲"
   → 跳转到 /volume-outline-generation?project=xxx&volume=2

2. 页面加载
   → 调用 GET /volume-outline-context
   → 左侧自动填充设定/大纲/上一卷细纲

3. 用户输入补充要求
   → 在"补充要求"textarea 中输入

4. 点击"✨ 开始生成"
   → 调用 POST /generate-volume-outline-v2（SSE）
   → 右侧实时流式输出

5. 生成完成
   → 显示渲染后的细纲
   → 用户可编辑修改
   → 点击"💾 保存" → 保存为 detailed_outline_vol{N}.md
   → 可选择"返回正文生成"继续写作
```

---

## 与正文生成页的关系

| 场景 | 行为 |
|------|------|
| 正文生成页 → 点击"生成本卷细纲" | 打开新标签页 `/volume-outline-generation?project=xxx&volume=N` |
| 细纲生成页 → 点击"返回正文生成" | 跳转回 `/chapter-generation?project=xxx&volume=N` |
| 细纲保存后 | 可选：关闭页面或返回正文生成页继续 |

---

## 成本估算

- 分卷细纲通常 10-20 章，prompt + 输出约 8000-15000 tokens
- DeepSeek-V4-Flash 约 0.02-0.04 元/卷
