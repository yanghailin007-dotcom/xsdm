# 番茄爆款提示词系统架构设计 v2.0

## 架构概述

```
SystemPrompt = 核心设定 + 战术规划 + 题材技法 + 文风技法 + AI约束 + 自检清单
```

### 六层架构图

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 6: 自检清单 (SelfCheck)                               │
│  └── 写前确认 → 写中检查 → 写后验证 → 质量评分              │
├─────────────────────────────────────────────────────────────┤
│  Layer 5: AI约束 (AIConstraints)                             │
│  └── 字数限制 + 格式规范 + 禁止事项 + 安全过滤              │
├─────────────────────────────────────────────────────────────┤
│  Layer 4: 文风技法 (WritingStyle)                            │
│  └── 快节奏 + 震惊流 + 对话技巧 + 微创新                    │
├─────────────────────────────────────────────────────────────┤
│  Layer 3: 题材技法 (GenreTechniques) ⭐核心分离层            │
│  └── 国运文/神豪文/修仙文...（完全隔离，互不干扰）          │
├─────────────────────────────────────────────────────────────┤
│  Layer 2: 战术规划 (TacticalPlanning)                        │
│  └── 阶段目标 + 本章类型 + 情绪曲线 + 爽点设计 + 钩子       │
├─────────────────────────────────────────────────────────────┤
│  Layer 1: 核心设定 (CoreSetting)                             │
│  └── 世界观 + 金手指 + 人设 + 核心卖点 + 爽点公式           │
└─────────────────────────────────────────────────────────────┘
```

## Layer 1: 核心设定 (CoreSetting)

### 作用
定义整部小说的"宪法"，所有章节必须遵守的基础设定。

### 数据结构

```yaml
# core_setting.yaml
core_setting:
  # 1. 世界观
  worldview:
    overview: "世界观概述（50字内）"
    core_rules:               # 核心规则（3-5条）
      - "规则1：..."
      - "规则2：..."
    power_system:             # 力量体系
      name: "体系名称"
      levels: ["F", "E", "D", "C", "B", "A", "S"]
      upgrade_method: "升级方式"
    world_rules:              # 世界运行规则
      - "死亡=真实死亡"
      - "国运值影响国家资源"
  
  # 2. 金手指
  golden_finger:
    name: "金手指名称"
    type: "系统/异能/宝物/传承"
    core_mechanism: "核心机制说明"
    current_level: "当前等级"
    current_ability: "当前能力"
    limitations: ["限制条件1", "限制条件2"]  # 防止无敌
    growth_path: ["阶段1", "阶段2", "阶段3"]  # 成长路线
    reward_sound: "系统提示音模板"  # 如：【叮！恭喜宿主...】
  
  # 3. 人物设定
  protagonist:
    name: "主角姓名"
    age: 22
    background: "身世背景"
    surface_identity: "表面身份"
    true_identity: "隐藏身份"
    personality_tags: ["冷静", "杀伐果断", "护短"]
    core_motivation: "核心动机"
    catchphrases: ["口头禅1", "口头禅2"]
    signature_actions: ["标志性动作1", "标志性动作2"]
    forbidden_behaviors: ["绝对不能做的事"]
  
  # 4. 核心卖点
  core_selling_point:
    one_sentence: "一句话卖点（如：开局扮演杀神白起）"
   差异化: "与同类作品的差异"
    hook_design: "核心钩子设计"
  
  # 5. 爽点公式（可复用的套路）
  burst_formula:
    pattern: "被看不起→展现实力→震惊众人→收获尊重"
    shock_hierarchy:           # 震惊层级
      - "现场当事人"
      - "围观者/弹幕"
      - "权威人士"
      - "全网/全城/全世界"
    reward_types: ["金钱", "地位", "能力", "人脉"]
```

### 使用规则
- **生成时机**：项目初始化时一次性生成
- **更新频率**：极少更新，除非发现设定冲突
- **使用方式**：全文复制到每章的System Prompt开头

## Layer 2: 战术规划 (TacticalPlanning)

### 作用
指导当前批次的章节生成，确保情绪曲线正确、节奏符合爆款规律。

### 数据结构

```yaml
# tactical_plan.yaml
tactical_plan:
  # 1. 当前阶段信息
  current_stage:
    name: "第一阶段：崭露头角"
    chapter_range: "1-30章"
    core_mission: "建立主角实力认知，积累初始粉丝"
    climax_chapter: 30
    climax_event: "首次国战，击败樱花国"
  
  # 2. 情绪曲线（阶段级）
  emotion_curve:
    - chapter_range: "1-5"
      emotion_type: "好奇+期待"
      intensity: 6
      hook_type: "身份悬念"
    - chapter_range: "6-15"
      emotion_type: "震惊+爽"
      intensity: 8
      hook_type: "实力逐步揭露"
    - chapter_range: "16-25"
      emotion_type: "紧张+反击"
      intensity: 7
      hook_type: "遭遇强敌"
    - chapter_range: "26-30"
      emotion_type: "爆爽+燃"
      intensity: 10
      hook_type: "绝地反击"
  
  # 3. 本章具体规划（每章不同）
  current_chapter:
    chapter_num: 7
    chapter_type: "打脸章"          # 打脸章/收获章/危机章/揭秘章/过渡章
    
    # 战术企图
    tactical_intent:
      primary_goal: "主角首次使用金手指，秒杀强敌"
      emotion_target: 
        type: "震惊"
        intensity: 8
        path: "质疑(3分)→震惊(8分)→跪服(9分)"
    
    # 爽点设计
    burst_design:
      target: "富二代XXX"
      shock_level: 3                  # 几层震惊
      reward: ["获得XXX", "身份提升"]
      face_slap_method: "实力碾压"
    
    # 必须出现的元素
    must_include:
      plot: ["主角出手", "众人震惊", "身份揭露"]
      characters: ["白月魁", "反派XX"]
      items: ["系统提示"]
    
    # 必须为下章埋的钩子
    next_chapter_hook:
      type: "危机降临"                # 危机降临/身份揭露/系统提示/时间锁
      content: "检测到SS级凶兽正在接近"
  
  # 4. 章节结构模板
  chapter_structure:
    first_300_words: "冲突/悬念开场，禁止环境描写"
    middle_part: "爽点递进，情绪积累"
    last_500_words: "高潮爆发 + 章尾钩子"
```

### 使用规则
- **生成时机**：每批次（30章）生成一次
- **更新频率**：每批次更新
- **使用方式**：当前章节的规划详情 + 阶段级情绪曲线

## Layer 3: 题材技法 (GenreTechniques) ⭐核心分离层

### 作用
这是**题材分离的核心**，确保神豪文不写出国运文的味道。

### 设计原则
1. **完全隔离**：不同题材的技法文件完全独立
2. **动态加载**：根据genre参数加载对应文件
3. **互斥元素**：明确禁止跨题材元素

### 数据结构

```yaml
# genre_techniques/国运文.yaml
genre: "国运文"
version: "1.0.0"

# 1. 震惊铺展顺序（题材特定）
shock_progression:
  order:
    - step: 1
      name: "现场反应"
      content: "直接见证事件的当事人表情、动作、心理、台词"
      format: "引号\"\"包裹"
    - step: 2
      name: "直播弹幕反应"
      content: "弹幕停滞→爆炸，主播失态/造梗"
      format: "【】包裹，ID+内容"
    - step: 3
      name: "各国官方反应"
      content: "从质疑到震惊到行动的递进"
      format: "引号\"\"包裹"
    - step: 4
      name: "全球层面影响"
      content: "联合国、世界格局变化"
      format: "宏观叙述"

# 2. 弹幕规范（国运文核心）
barrage_rules:
  required: true
  min_count: 8
  max_count: 12
  format: "【ID：内容】"
  templates:
    - type: "龙国支持"
      examples: ["【龙国观众：卧槽！这也行？】", "【龙国粉丝：苏神牛逼！！！】"]
    - type: "外国嘲讽"
      examples: ["【漂亮国观众：不可能！一定是作弊！】", "【樱花观众：龙国完了！】"]
    - type: "专家分析"
      examples: ["【专家：这违背了物理学常识！】", "【技术流：数据显示能量值爆表！】"]
    - type: "官方账号"
      examples: ["【龙国国运指挥部：密切关注中】"]

# 3. 系统提示音（国运文特色）
system_prompts:
  - type: "国运提升"
    template: "【龙国国运+XXX】【全球排名上升至第X位】"
  - type: "扮演度提升"
    template: "【扮演度提升至X.X%】【解锁新能力：XXX】"
  - type: "全球公告"
    template: "【全球公告】龙国选手XXX完成越级击杀，奖励国运值+X%！"

# 4. 数据展示要求
data_visualization:
  required: true
  items:
    - "国运值变化（天空异象）"
    - "战力数值/气场表现"
    - "全球排名变化"
    - "与他国对比数据"

# 5. 禁用元素（关键！防止混淆）
forbidden_elements:
  - "校园场景（教务处、奖学金、江城大学等）"
  - "金钱交易/消费返利（这是神豪文的）"
  - "人生模拟器系统（除非大纲明确指定）"
  - "都市日常/职场生活"

# 6. 必须元素（检查清单）
required_elements:
  - "全球直播元素"
  - "弹幕互动（≥8条）"
  - "国运相关数值变化"
  - "国家荣誉感体现"

# 7. 对话占比达成方式
dialogue_achievement:
  methods:
    - "增加弹幕密度（每章8-10条）"
    - "增加角色对话（用引号）"
    - "增加围观反应（路人台词）"
    - "增加系统提示（用【】）"
```

## Layer 4: 文风技法 (WritingStyle)

### 作用
所有题材通用的写作技巧，提升阅读体验。

### 数据结构

```yaml
# writing_style.yaml
writing_style:
  name: "番茄快节奏爽文"
  
  # 1. 段落规范
  paragraph:
    max_lines: 3                    # 每段最多3行
    avg_length: "30-50字"           # 平均长度
    mobile_first: true              # 手机优先
  
  # 2. 句子规范
  sentence:
    short_sentence_ratio: 0.6       # 短句(<10字)占比≥60%
    max_length: 15                  # 单句最长15字
    colloquial: true                # 口语化
  
  # 3. 对话规范
  dialogue:
    ratio: 0.5                      # 对话占比≥50%
    format: "引号\"\"包裹"
    one_per_paragraph: true         # 一句一段
    tags: ["他说", "笑道", "冷声道"]  # 对话标签
  
  # 4. 节奏控制
  pacing:
    conflict_first_300: true        # 前300字必须有冲突
    mini_burst_every_1000: true     # 每1000字一个小爽点
    hook_last_50: true              # 最后50字是钩子
    no_dialogue_limit: 200          # 禁止连续200字无对话
  
  # 5. 震惊流技法
  shock_flow:
    principles:
      - "先写反应，后写原因"
      - "层层递进，禁止跳级"
      - "数字量化，拒绝模糊"
    forbidden: ["第一层震惊", "第二层震惊"]  # 禁止层级标签
  
  # 6. 情绪控制
  emotion:
    transitions_per_chapter: 3      # 一章内情绪转变至少3次
    climax_intensity: 8             # 高潮部分情绪强度≥8/10
    no_regression: true             # 爽后不能突然压抑
```

## Layer 5: AI约束 (AIConstraints)

### 作用
硬性约束，确保AI输出格式统一、可解析。

### 数据结构

```yaml
# ai_constraints.yaml
ai_constraints:
  # 1. 字数约束
  word_count:
    target: 2200                    # 目标字数
    min: 2000                       # 最低
    max: 2500                       # 最高
    tolerance: 0.1                  # 容错10%
  
  # 2. 输出格式
  output_format:
    type: "JSON"                    # JSON/Markdown/纯文本
    schema:
      title: 
        type: "string"
        length: "8-14字"
        forbidden_prefix: ["第X章", "第X章："]
      content:
        type: "string"
        length: "2000-2500字"
        forbidden: ["第X章标题在正文开头"]
    separator: "---标题--- / ---正文---"
  
  # 3. 格式规范
  format_rules:
    dialogue: "引号\"\""
    system_barrage: "【】"
    paragraph_max_lines: 3
  
  # 4. 禁止事项
  forbidden:
    content:
      - "爽点回退（爽后突然压抑）"
      - "预告欺诈（章尾预告不兑现）"
      - "人设崩塌"
      - "战力崩坏"
      - "圣母心（该杀不杀）"
      - "逻辑硬伤"
      - "水文凑字"
    format:
      - "正文开头写'第X章'"
      - "标题重复出现在正文"
      - "返回非JSON格式"
  
  # 5. 安全过滤
  safety:
    sensitive_words_filter: true
    political_correctness: true
    violence_level: "轻度（符合番茄规范）"
```

## Layer 6: 自检清单 (SelfCheck)

### 作用
强制AI生成后进行自检，提高一次通过率。

### 数据结构

```yaml
# self_check.yaml
self_check:
  # 1. 写前自检（生成前确认理解）
  pre_writing:
    - item: "是否理解本章战术企图？"
      critical: true
    - item: "情绪目标是否明确？（类型+强度）"
      critical: true
    - item: "必须出现的元素是否已知？"
      critical: false
  
  # 2. 写中自检（生成过程中检查）
  during_writing:
    - item: "前300字是否进入冲突/悬念？"
      check_point: "300字"
    - item: "当前字数是否合理？（避免超长）"
      check_point: "每500字"
    - item: "是否偏离战术企图？"
      check_point: "每1000字"
    - item: "对话占比是否达标？"
      check_point: "每1000字"
  
  # 3. 写后自检（生成后验证）
  post_writing:
    format_check:
      - item: "JSON格式正确？"
        validator: "json_schema"
      - item: "字数在2000-2500之间？"
        validator: "word_count"
      - item: "无'第X章'字样在正文开头？"
        validator: "regex_check"
    
    content_check:
      - item: "章尾有强钩子？"
        validator: "hook_detector"
      - item: "人设保持一致？"
        validator: "character_consistency"
      - item: "无禁止元素？"
        validator: "forbidden_checker"
    
    genre_specific_check:
      国运文:
        - item: "弹幕数量≥8条？"
          validator: "barrage_counter"
        - item: "弹幕格式正确（【】包裹）？"
          validator: "barrage_format"
        - item: "有国运值相关元素？"
          validator: "keyword_check"
      
      神豪文:
        - item: "金额至少3处且精确？"
          validator: "money_precision"
        - item: "有系统返利提示音？"
          validator: "keyword_check"
        - item: "有路人价格计算？"
          validator: "keyword_check"
  
  # 4. 质量评分
  quality_score:
    metrics:
      - name: "番茄得分"
        weight: 0.4
        min: 65
      - name: "对话占比"
        weight: 0.2
        min: 0.5
      - name: "情绪强度"
        weight: 0.2
```

## 组装流程

```python
class PromptAssembler:
    """
    提示词组装器
    将六层内容动态组装成完整System Prompt
    """
    
    def assemble(self, context: AssemblyContext) -> str:
        """
        组装流程
        """
        sections = []
        
        # Layer 1: 核心设定（项目级）
        sections.append(self.load_core_setting(context.project_id))
        
        # Layer 2: 战术规划（批次级+章节级）
        sections.append(self.load_tactical_plan(
            context.batch_id, 
            context.chapter_num
        ))
        
        # Layer 3: 题材技法（动态加载）⭐关键
        sections.append(self.load_genre_techniques(context.genre))
        
        # Layer 4: 文风技法（全局）
        sections.append(self.load_writing_style())
        
        # Layer 5: AI约束（全局）
        sections.append(self.load_ai_constraints())
        
        # Layer 6: 自检清单（全局）
        sections.append(self.load_self_check(context.genre))
        
        return "\n\n".join(sections)
    
    def load_genre_techniques(self, genre: str) -> str:
        """
        动态加载题材技法
        """
        file_path = f"genre_techniques/{genre}.yaml"
        if not exists(file_path):
            file_path = "genre_techniques/通用.yaml"
        
        return load_yaml(file_path)
```
