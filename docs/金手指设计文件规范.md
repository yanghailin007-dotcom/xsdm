# 金手指设计文件规范

## 概述

金手指设计文件是**一阶段产物**的重要组成部分，用于详细定义小说中金手指（系统/金手指/特殊能力）的各项参数。该文件保存在 `phase_one_products/金手指设计.json`。

## 文件位置

```
project_root/
└── phase_one_products/
    ├── 角色设计.json
    ├── 金手指设计.json  ← 本文件
    └── plan.json
```

## 字段规范

### 必填字段

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `name` | string | 金手指名称 | "每日随机盲盒系统" |
| `type` | string | 金手指类型 | "系统流"/"签到流"/"空间类" |
| `core_mechanism` | string | 核心机制描述 | "每日零点开启随机盲盒，消费获得随机奖励" |

### 激活条件（activation）

```json
{
  "activation": {
    "trigger": "绑定任意一张银行卡",
    "scene": "主角走投无路，准备离开城市时",
    "initial_reward": "新手大礼包：必得现金盲盒×3"
  }
}
```

### 能力阶段（abilities）

```json
{
  "abilities": [
    {
      "stage": "初始",
      "ability": "每日零点获得1个普通盲盒",
      "unlock_condition": "系统自动发放"
    },
    {
      "stage": "LV.10",
      "ability": "解锁稀有盲盒",
      "unlock_condition": "等级达到10级"
    }
  ]
}
```

### 升级体系（upgrade_system）

```json
{
  "upgrade_system": {
    "metric": "经验值",
    "formula": "每消费1万元=100经验，每1000经验升1级",
    "max_level": "99级（神级）"
  }
}
```

### 限制条件（limitations）

**必须有，否则金手指太无敌**

```json
{
  "limitations": [
    "盲盒奖励完全随机，无法指定",
    "每日零点重置，未开启盲盒不累积",
    "系统奖励不能直接用于违法活动"
  ]
}
```

### 系统提示音（reward_sound）

```json
{
  "reward_sound": "【叮！恭喜宿主获得[盲盒品质]盲盒×1！】"
}
```

### 特殊机制（special_mechanics）

```json
{
  "special_mechanics": [
    {
      "name": "暴击机制",
      "description": "极低概率触发10倍暴击，奖励翻10倍",
      "trigger": "纯随机"
    }
  ]
}
```

### 世界规则（world_rules）

由金手指引出的世界观规则：

```json
{
  "world_rules": [
    {
      "rule": "金钱即权力",
      "description": "资本可以影响规则，高消费可解锁特殊剧情"
    }
  ]
}
```

### 剧情线索（plot_hooks）

与金手指相关的剧情线索：

```json
{
  "plot_hooks": [
    {
      "name": "隐藏任务线",
      "description": "消费特定类型商品触发隐藏盲盒任务",
      "trigger_chapter": "第3-5章"
    }
  ]
}
```

### 使用示例（examples）

```json
{
  "examples": {
    "early_stage": "【叮！开启普通盲盒！获得：现金100万元！】",
    "mid_stage": "【叮！开启稀有盲盒！获得：格斗精通技能！】",
    "late_stage": "【叮！开启传说盲盒！获得：未来科技图纸！】"
  }
}
```

### 叙事指导（narrative_guidelines）

```json
{
  "narrative_guidelines": [
    "每次开盲盒必须有系统提示音",
    "奖励要有具体数值，不能模糊",
    "高价值奖励要有周围人的震惊反应"
  ]
}
```

## 在V2架构中的使用

### Layer 1.2 渲染

System Prompt 中的金手指设定会从该文件加载，包含：
- 名称、类型、核心机制
- 激活条件、初始奖励
- 能力阶段（前3个）
- 升级体系
- 限制条件（重点）
- 系统提示音模板
- 特殊机制
- 叙事要求

### World State 初始化

世界状态管理器会读取该文件初始化：
- `system_rules.system_name` ← `name`
- `system_rules.system_type` ← `type`
- `system_rules.current_level` ← `abilities[0].stage`
- `system_rules.unlocked_abilities` ← 初始阶段的能力

## 注意事项

1. **限制条件必须有**：没有限制的金手指会导致剧情崩坏
2. **数值要具体**：避免"大量"、"很多"等模糊词汇
3. **阶段要清晰**：能力升级要有明确的阶段划分
4. **提示音要规范**：统一使用【】包裹
5. **与题材匹配**：不同类型的金手指要符合题材特点
