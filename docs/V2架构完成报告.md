### 核心特性

1. **六层架构**
   - Layer 1: 核心设定（CoreSetting）
   - Layer 2: 战术规划（TacticalPlanning）
   - Layer 3: 题材技法（GenreTechniques）
   - Layer 4: 文风技法（WritingStyle）
   - Layer 5: AI约束（AIConstraints）
   - Layer 6: 自检清单（SelfCheck）

2. **题材分离**
   - 国运文、神豪文、通用 三种题材技法完全隔离
   - 动态加载对应题材配置
   - 自动回退到通用模板

3. **网文情绪曲线**
   - 打脸章: 虐(4)→急(7)→爽(9)→悬(7)
   - 收获章: 悬(7)→惊(8)→爽(10)→悬(7)
   - 危机章: 怕(8)→虐(5)→燃(10)→爽(8)
   - 揭秘章: 悬(8)→惊(7)→惊(9)→惊(10)→悬(9)

4. **使用方法**

```python
from web.services.market_driven.v2_architecture import (
    PromptAssemblerV2, AssemblyContext
)

# 创建组装器
assembler = PromptAssemblerV2("国运文")

# 创建上下文
context = AssemblyContext(
    novel_title="开局扮演杀神白起",
    chapter_num=7,
    protagonist_name="苏辰",
    chapter_type="打脸章"
)

# 组装提示词
prompt = assembler.assemble(context)
```

或使用快捷函数:

