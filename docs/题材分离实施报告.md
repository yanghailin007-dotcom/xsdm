
## 扩展题材

要添加新题材，只需：

1. 创建 `genre_techniques/新题材.yaml`
2. 定义该题材的：
   - 震惊铺展顺序
   - 专用元素（如弹幕/金钱/境界）
   - 系统提示音
   - 禁用元素（防止混淆）
   - 必须元素（检查清单）

示例：修仙文
```yaml
genre: "修仙文"
shock_progression:
  steps:
    - name: "同门震惊"
    - name: "长老评估"
    - name: "宗主关注"
    - name: "修仙界震动"

system_prompts:
  - type: "突破"
    template: "【轰！天地变色，XXX突破至XXX境！】"

required_elements:
  - element: "境界突破描写"
  - element: "天地异象"
```
