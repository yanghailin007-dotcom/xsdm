# 网文情绪曲线设计

## 问题：为什么"起-承-转-合"不适合网文？

| 维度 | 传统文学（起承转合） | 番茄网文 |
|------|---------------------|----------|
| **节奏** | 慢热，层层铺垫 | 快节奏，前300字必须入戏 |
| **情绪基调** | 多样化，可压抑可平淡 | 以"爽"为主，压抑只用于对比 |
| **章节结构** | 完整闭环 | 章章有钩子，连续高潮 |
| **读者期待** | 品味文学性 | 获得即时爽感 |

**"起-承-转-合"的问题**：
- "承"=铺垫 → 网文读者没耐心看铺垫
- "合"=收尾 → 网文章尾必须是钩子，不能收尾

## 网文情绪标签系统

### 核心情绪（8种）

```yaml
情绪标签:
  爽: 
    定义: "主角成功打脸、获得奖励、实力提升"
    强度: 8-10
    适用: "打脸章、收获章"
  
  燃:
    定义: "热血战斗、为国争光、逆风翻盘"
    强度: 9-10
    适用: "战斗章、国战章"
  
  甜:
    定义: "感情升温、暧昧互动、撒糖"
    强度: 6-8
    适用: "感情线章节"
  
  悬:
    定义: "悬念、危机、未知"
    强度: 7-9
    适用: "揭秘章、危机章"
  
  虐:
    定义: "主角受委屈、被误解、暂时受挫"
    强度: 4-6
    适用: "压抑章（必须快速反转）"
  
  急:
    定义: "时间紧迫、倒计时、争分夺秒"
    强度: 7-9
    适用: "限时任务章"
  
  惊:
    定义: "震惊、意外、意想不到"
    强度: 8-10
    适用: "反转章、揭秘章"
  
  怕:
    定义: "恐怖、危险、生死危机"
    强度: 6-8
    适用: "恐怖副本、生存危机"
```

### 情绪强度等级

```yaml
强度等级:
  10: "爆点 - 全书大高潮，读者尖叫"
  9:  "高潮 - 阶段性大爽点"
  8:  "爽点 - 常规打脸/收获"
  7:  "紧张 - 危机/悬念"
  6:  "期待 - 铺垫，即将爆发"
  5:  "过渡 - 信息补充，低强度"
  4:  "压抑 - 短暂压抑，即将反转"
  3:  "平淡 - 尽量避免"
  2:  "无聊 - 必须删除"
  1:  "毒点 - 绝对禁止"
```

## 章节类型与情绪曲线

### 1. 打脸章（最常用）

```yaml
打脸章情绪曲线:
  前300字:
    情绪: "虐/压抑(4-5)"
    内容: "反派嚣张，主角被看不起"
  
  中段:
    情绪: "急/悬(6-7)→惊(8)"
    内容: "冲突爆发，主角展现实力"
  
  高潮:
    情绪: "爽/燃(9-10)"
    内容: "反派被打脸，众人震惊"
  
  章尾:
    情绪: "悬(7)+期待(6)"
    内容: "新钩子出现"

曲线示意: 4→6→8→10→7
```

### 2. 收获章

```yaml
收获章情绪曲线:
  前300字:
    情绪: "悬(7)"
    内容: "面临挑战/考验"
  
  中段:
    情绪: "惊(8)→爽(9)"
    内容: "通过考验，获得奖励"
  
  高潮:
    情绪: "爽(10)"
    内容: "展示收获，震惊众人"
  
  章尾:
    情绪: "悬(7)+期待(6)"
    内容: "新目标/新挑战"

曲线示意: 7→8→10→7
```

### 3. 危机章

```yaml
危机章情绪曲线:
  前300字:
    情绪: "怕/悬(8)"
    内容: "危机降临，生死存亡"
  
  中段:
    情绪: "虐(5)→急(8)"
    内容: "绝境挣扎，寻找生机"
  
  高潮:
    情绪: "燃/爽(10)"
    内容: "逆转取胜，绝境重生"
  
  章尾:
    情绪: "爽(8)+悬(6)"
    内容: "胜利但留下隐患"

曲线示意: 8→5→10→8
```

### 4. 揭秘章

```yaml
揭秘章情绪曲线:
  前300字:
    情绪: "悬(8)"
    内容: "悬念加深，谜团重重"
  
  中段:
    情绪: "惊(7)→惊(9)"
    内容: "逐步揭秘，层层反转"
  
  高潮:
    情绪: "惊(10)+爽(8)"
    内容: "核心真相揭露"
  
  章尾:
    情绪: "悬(9)"
    内容: "更大谜团出现"

曲线示意: 8→7→9→10→9
```

## 阶段级情绪曲线模板

### 第一阶段（1-30章）：崭露头角

```yaml
阶段情绪规划:
  1-5章: 
    主情绪: "悬+期待"
    强度: "5→7"
    说明: "主角入局，金手指激活，建立期待感"
  
  6-15章:
    主情绪: "爽"
    强度: "7→9"
    说明: "首次展现实力，连续打脸，建立爽感认知"
  
  16-25章:
    主情绪: "虐→燃"
    强度: "4→10"
    说明: "遭遇强敌，短暂压抑后强势反击"
  
  26-30章:
    主情绪: "燃+爽"
    强度: "10"
    说明: "阶段大高潮，为国争光/名震一方"
```

## 神豪文 vs 国运文 情绪差异

### 神豪文情绪特点

```yaml
神豪文情绪:
  主情绪: "爽"
  辅情绪: "惊（价格震惊）"
  
  典型曲线:
    - "平淡(被看不起)→爽(消费)→更爽(返利)→爽爆(震惊全场)"
  
  强度分布:
    - "60%时间强度≥8（持续高爽）"
  
  压抑限制:
    - "压抑不超过500字，必须快速反转"
```

### 国运文情绪特点

```yaml
国运文情绪:
  主情绪: "燃+爽"
  辅情绪: "悬（危机）"
  
  典型曲线:
    - "悬(危机)→虐(困境)→燃(反击)→爽(胜利+国运提升)"
  
  强度分布:
    - "大高潮必须达到10（为国争光）"
  
  特殊要求:
    - "每次胜利必须有国家层面反馈（国运值、排名）"
```

## 情绪曲线在提示词中的使用

### 错误示例（起承转合）

```
情绪曲线：起-承-转-合
→ AI理解为：铺垫→发展→高潮→结局
→ 结果：写出了传统文学结构
```

### 正确示例（网文节奏）

```
本章类型：打脸章
情绪曲线：虐(4)→急(7)→爽(9)→悬(7)

具体安排：
- 前300字（虐4）：反派嚣张，主角被看不起
- 500-1500字（急7）：冲突升级，一触即发
- 1500-2000字（爽9）：主角出手，震惊全场
- 最后50字（悬7）：新危机出现，钩子
```

## 实现建议

### 1. 替换情绪曲线参数

```python
# 旧
emotion_curve = "起-承-转-合"

# 新
emotion_curve = {
    "type": "打脸章",
    "curve": "虐(4)→急(7)→爽(9)→悬(7)",
    "breakdown": {
        "0-300": {"情绪": "虐", "强度": 4, "内容": "反派嚣张"},
        "300-1500": {"情绪": "急", "强度": 7, "内容": "冲突升级"},
        "1500-2000": {"情绪": "爽", "强度": 9, "内容": "主角出手"},
        "2000-2200": {"情绪": "悬", "强度": 7, "内容": "新钩子"}
    }
}
```

### 2. 在提示词中明确情绪要求

```markdown
## 本章情绪要求
- 类型：打脸章
- 整体曲线：虐(4)→急(7)→爽(9)→悬(7)

### 分段要求
前300字（虐，强度4）：
- 反派必须足够嚣张
- 主角被严重看不起
- 读者感到憋屈，期待反转

中段（急→爽，强度7→9）：
- 冲突快速升级
- 主角展现实力，震惊众人
- 打脸要彻底，不要圣母

章尾（悬，强度7）：
- 必须留下强钩子
- 新危机/新挑战出现
- 让读者迫不及待想看下章
```

## 总结

| 维度 | 传统（起承转合） | 网文（情绪曲线） |
|------|-----------------|-----------------|
| **基本单位** | 起承转合四段 | 情绪强度数值 |
| **核心目标** | 完整叙事 | 持续爽感 |
| **章节结尾** | 合（收尾） | 悬（钩子） |
| **节奏控制** | 慢热 | 前300字入戏 |
| **情绪基调** | 多样化 | 以爽为主 |

**关键改变**：用"虐→急→爽→悬"替代"起-承-转-合"，用强度数值（4-10）替代抽象阶段。
