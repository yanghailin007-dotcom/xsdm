# V2 六层架构完整实现文档

## 架构概览

V2 六层架构将章节生成提示词分为六个层次，清晰分层便于调试和调优：

```
┌─────────────────────────────────────────────────────────────────┐
│                     SYSTEM PROMPT (系统提示词)                   │
│                       (高频约束，长期保持)                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【Layer 1】核心设定 (宪法级，全文遵守)                           │
│    ├── 1.1 主角人设（姓名/身份/性格/禁止行为）                    │
│    ├── 1.2 金手指设定（名称/机制/当前等级）                       │
│    ├── 1.3 世界核心规则（金钱即权力/高维观察者）                  │
│    ├── 1.4 核心卖点（必须体现的爽点类型）                         │
│    └── 1.5 爽点公式（压抑→铺垫→反转→高潮→收获→钩子）           │
│                                                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【Layer 2】战术规划 (批次级，本章执行)                           │
│    ├── 2.1 当前阶段信息（初期/中期/后期）                         │
│    ├── 2.2 本章战术目标（类型/情绪/爽点/打脸）                   │
│    ├── 2.3 章节结构设计（0-15%/15-45%/45-75%/75-90%/90-100%）   │
│    └── 2.4 情绪节奏控制（曲线/转变次数/高潮要求）                 │
│                                                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【Layer 3】题材技法 (神豪文/国运文专项)                          │
│    ├── 震惊铺展顺序（5步递进）                                    │
│    ├── 系统提示音模板（【叮！...】格式）                          │
│    ├── 必须元素（精确金额/弹幕/国运值）                           │
│    └── 禁用元素（防止题材混淆）                                   │
│                                                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【Layer 4】文风技法 (番茄快节奏爽文)                             │
│    ├── 段落规范（3-4行/段）                                       │
│    ├── 句子规范（短句≥40%）                                       │
│    ├── 对话规范（占比≥50%）                                       │
│    ├── 节奏控制（前300字冲突/每1000字爽点/章尾钩子）              │
│    └── 震惊流技法（先反应后原因/层层递进）                        │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                       USER PROMPT (用户提示词)                   │
│                        (低频变化，每章更新)                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【Layer 5】AI约束 + 情绪曲线 + 输出格式                          │
│    ├── 5.1 字数约束（2000-2500字）                                │
│    ├── 5.2 情绪节奏规划（章节类型/曲线/情绪点位）                 │
│    ├── 5.3 输出格式（---标题---/---正文---）                     │
│    └── 5.4 禁止事项（爽点回退/预告欺诈/人设崩塌）                 │
│                                                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【Layer 6】自检清单 (生成后必须完成)                             │
│    ├── 6.1 写前确认（题材/人设/情绪曲线）                         │
│    ├── 6.2 写作后-格式检查（字数/分隔符/钩子）                    │
│    ├── 6.3 写作后-内容检查（情节/爽点/人设）                      │
│    └── 6.4 写作后-题材检查（神豪文/国运文专项检查）               │
│                                                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【任务指令】生成章节内容                                         │
│    ├── 任务1：本章事件                                            │
│    ├── 任务2：爽点设计                                            │
│    ├── 任务3：打脸设计                                            │
│    └── 任务4：章尾钩子                                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 使用方法

### 1. 查看生成的提示词分层
在 API 调用日志中查看：
```
========== 系统提示 (System Prompt) ==========
## 【Layer 1】核心设定（宪法级，全文遵守）
## 【Layer 2】战术规划（批次级，本章执行）
## 【Layer 3】题材技法 - 神豪文
## 【Layer 4】文风技法 - 番茄快节奏爽文

========== 用户提示 (User Prompt) ==========
## 【Layer 5】AI约束 + 情绪曲线 + 输出格式
## 【Layer 6】自检清单（生成后必须完成）
## 【任务指令】生成章节内容
```

### 2. 调优某一层
例如修改 Layer 1 的主角人设：
```yaml
# prompt_packages/default/market_driven/v2_config/core_setting.yaml
protagonist:
  name: "新的主角名"
  personality_tags:
    - "新的性格标签"
```

### 3. 重启生效
修改后重启 Flask 服务器：
```bash
python start.py
```

## 调试优势

| 问题类型 | 定位层级 | 解决方法 |
|---------|---------|---------|
| 主角性格不一致 | Layer 1 | 修改主角人设 |
| 章节结构混乱 | Layer 2 | 调整章节结构设计 |
| 题材元素缺失 | Layer 3 | 检查必须元素清单 |
| 节奏拖沓 | Layer 4 | 调整文风规范 |
| 字数不达标 | Layer 5 | 修改字数约束 |
| 格式错误 | Layer 6 | 加强格式检查 |

## 提示词长度统计

| 层级 | 典型长度 | 说明 |
|-----|---------|-----|
| System Prompt (Layer 1-4) | ~2500 字符 | 长期保持，每会话发送一次 |
| User Prompt (Layer 5-6) | ~1400 字符 | 每章更新，包含具体任务 |
| **总计** | **~3900 字符** | 完整六层架构 |
